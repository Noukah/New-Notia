# Carpeta de Iconos de Notia (`assets/icons/`)

Coloca aquí tus archivos de iconos en formato **SVG** (recomendado para máxima nitidez y escalabilidad) o **PNG**.

---

### Nombres sugeridos para los iconos de la Pantalla Principal:

#### Barra Superior:
* `notes_library.svg` ➔ Botón superior izquierdo (visor / biblioteca de notas)
* `settings.svg` ➔ Botón superior derecho (engranaje / ajustes)

#### Círculos Centrales (Modos):
* `mic.svg` ➔ Icono principal de grabación de voz
* `write_note.svg` ➔ Icono principal de escritura manual

#### Dock Inferior (Barra Flotante):
* `create_folder.svg` ➔ Botón circular azul con '+' (crear carpetas o grupos)
* `notifications.svg` ➔ Campana de notificaciones
* `search.svg` ➔ Lupa de búsqueda de notas
* `import_audio.svg` ➔ Carpeta amarilla para importar audio externo

#### Perfiles de IA (Submenú de 5 botones):
* `profile_school.svg` ➔ Perfil Escuela (apuntes de clase)
* `profile_meetings.svg` ➔ Perfil Reuniones (minutas)
* `profile_work.svg` ➔ Perfil Trabajo (estado y bloqueos)
* `profile_ideas.svg` ➔ Perfil Ideas (lluvia de ideas)
* `profile_projects.svg` ➔ Perfil Proyectos (hitos y alcance)

#### Controles de Grabación Activa:
* `trash.svg` ➔ Descartar / eliminar grabación
* `pause.svg` ➔ Pausar grabación
* `play.svg` ➔ Reanudar grabación
* `done.svg` ➔ Detener y transcribir con Sherpa ONNX
